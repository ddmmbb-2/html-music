# HTML Music

**不用安裝播放器，一個 HTML 就能帶走整個音樂庫，還能同時播放多首音樂。**

HTML Music 延續 HTML Office 系列借鑑 TiddlyWiki 的單檔設計，把音樂庫、分類管理、播放器與音訊內容放在同一個 HTML 裡。

它不只是一般的音樂播放器，也是一個簡單的多軌音樂播放工作台。可以一邊播放背景音樂，一邊加入環境音效，並在需要時快速降低音量、恢復音量或淡出停止。

👉 **HTML Office 系列首頁：** [https://office.ddmmbb.org/](https://office.ddmmbb.org/)

## 主要功能

### 音樂庫管理

- 直接在網頁內新增、重新命名及刪除分類。
- 拖曳音樂檔案加入指定分類，支援一次匯入多首音樂。
- 匯入整個資料夾，依子資料夾建立分類。
- 透過拖曳或下拉選單移動歌曲分類。
- 重新命名或移除音樂，不會刪除電腦中的原始音樂檔案。
- 即時搜尋音樂名稱與分類。
- 顯示音樂庫容量與播放中的歌曲。

### 多軌播放與音量控制

- 同時播放多首音樂，不會因播放另一首而中斷。
- 每首音樂可獨立播放、暫停、停止、調整進度及設定循環。
- 全域音量控制，統一調整所有音樂的音量。
- 一鍵切換至 16% 或 100% 音量。
- 平滑漸變至 16% 或 100%。
- 漸變時間可選擇 1、3、5、10、20 秒。
- 一鍵淡出並停止所有音樂，或立即全部停止。

### 操作介面

- 支援深色與淺色主題。
- 播放中的音樂有明顯的視覺提示。
- 編輯模式與播放模式切換，避免播放時誤觸編輯功能。
- 固定底部音量控制台。
- 響應式排版，適合不同尺寸的螢幕。

## 如何使用

1. 下載專案中的 HTML 檔案。
2. 使用桌面版 Chrome 或 Edge 開啟。
3. 建立需要的音樂分類。
4. 將音樂拖曳至指定分類，也可以直接匯入資料夾。
5. 設定需要循環播放的音樂。
6. 點選「儲存 HTML」，下載包含所有音樂的新 HTML 檔案。
7. 下次直接開啟新儲存的 HTML 即可繼續播放及編輯。

## 適合使用的情境

- 店面、餐廳、咖啡廳的背景音樂。
- 活動、會議、典禮及舞台的音效控制。
- 桌遊、角色扮演遊戲的背景音樂與環境音效。
- 閱讀、工作、冥想時搭配不同的環境聲音。
- 建立可以隨身攜帶的個人離線音樂庫。

## 單檔設計

音樂並不是以外部檔案路徑連結，而是在儲存時轉換為 Base64 資料並嵌入 HTML。

因此儲存完成後，只要攜帶一個 HTML 檔案，就能在其他電腦上使用同一個音樂庫，不需要另外攜帶音樂資料夾，也不需要 PHP、資料庫、伺服器或網路連線。

> [!IMPORTANT]
> 網頁內的修改不會自動寫回原始 HTML。新增、刪除或修改分類與音樂後，請使用「儲存 HTML」，確認下載完成，並在下次使用時開啟新儲存的檔案。

## 音樂格式與檔案容量

可匯入 MP3、WAV、OGG、M4A、AAC、FLAC 等常見音訊檔案，實際播放支援取決於瀏覽器與作業系統的解碼能力。

Base64 編碼會讓音訊資料的容量增加約三分之一，另外還有少量 HTML 程式碼與分類資料。

| 原始音樂容量 | 儲存後的 HTML 約略容量 |
| --- | --- |
| 20 MB | 27 MB |
| 50 MB | 67 MB |
| 100 MB | 133 MB |
| 300 MB | 400 MB |

目前沒有設定固定的 20 MB 容量上限，音樂總容量超過 100 MiB 時會出現儲存提醒。實際可使用的容量仍取決於瀏覽器及電腦記憶體，建議大型音樂庫依用途分成不同 HTML 檔案。

## 技術與設計理念

- 使用原生 HTML、CSS 與 JavaScript。
- 使用瀏覽器內建的音訊播放及檔案讀取功能。
- 無需外部函式庫、後端服務或資料庫。
- 音樂、分類與個別循環設定可隨單檔保存。
- 原始碼以便於 LLM 理解、定位、修改及後續維護為設計方向。

HTML Music 並不打算取代所有專業音樂播放器或混音軟體，而是希望讓音樂庫變成一個可以編輯、播放、複製、分享及帶走的普通檔案。
